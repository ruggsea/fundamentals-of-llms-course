# Slide assets

Pictures used by the decks in `lectures/`. The engravings are public domain (see the licences in the
repo-root `assets/README.md`).

## Avatars and logos (added 8 October 2026)

- `avatars/ruggsea.webp`, `avatars/lorrenz.webp` — the Bluesky profile pictures of Ruggero Marino Lazzaroni
  (@ruggsea.eurosky.social) and Lorenz Prattes (@lorrenz.bsky.social), fetched from the Bluesky CDN via the
  public `app.bsky.actor.getProfile` API for the lecture 1 Bluesky slide. Our own pictures.
- `pi-logo.svg` — the pi logo from <https://pi.dev/logo-auto.svg> (the pi coding agent, used in the lecture 1
  agentic-coding slide). Source is the project's own site; replace with a local redraw if licence questions
  come up.
